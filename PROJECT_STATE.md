# TripMind AI

## Overview
TripMind AI is a standalone AI-powered travel planner built with Node.js, Express, EJS, Bootstrap, MongoDB and Google Gemini.

Architecture:
- MVC
- Thin Controllers
- Service Layer
- Prompt Layer
- AI Gateway
- Provider Pattern
- JSON Validation Pipeline
